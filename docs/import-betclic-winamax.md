# Tutoriel d'import des mains (Betclic & Winamax)

Ce guide explique comment récupérer vos historiques de mains et les importer dans `Poker Hand Review`.

---

## 1) Importer dans l'application

1. Ouvrez `Poker Hand Review`.
2. Cliquez sur **Importer fichiers**.
3. Sélectionnez un ou plusieurs fichiers `.txt`.

Alternative : vous pouvez aussi **glisser-déposer** les fichiers `.txt` directement sur le bouton **Importer fichiers**.

![Capture - bouton importer](./images/import-bouton.png)

---

## 2) Betclic : récupérer les historiques

1. Ouvrez Betclic Poker.
2. Allez dans les paramètres d'historique de mains.
3. Activez l'enregistrement local des historiques.
4. Ouvrez le dossier de sauvegarde des historiques.
5. Copiez les fichiers `.txt` voulus.
6. Importez ces fichiers dans `Poker Hand Review`.

![Capture - réglages Betclic](./images/betclic-reglages-historique.png)
![Capture - dossier Betclic](./images/betclic-dossier-historique.png)

---

## 3) Winamax : récupérer les historiques

1. Ouvrez Winamax.
2. Allez dans les paramètres / options.
3. Activez la sauvegarde de l'historique local.
4. Ouvrez le dossier où Winamax stocke les historiques.
5. Récupérez les fichiers `.txt`.
6. Importez-les dans `Poker Hand Review`.

![Capture - réglages Winamax](./images/winamax-reglages-historique.png)
![Capture - dossier Winamax](./images/winamax-dossier-historique.png)

---

## 4) Format attendu

- Fichiers texte `.txt`
- Historique brut exporté par la room (Betclic / Winamax)

Si aucun coup ne s'affiche après import :

- vérifiez que vous avez bien pris les fichiers d'historique de mains (et pas un autre export),
- vérifiez que le fichier n'est pas vide,
- réessayez avec un fichier plus récent.

---

## 5) Conseils pratiques

- Importez par petites séries (ex: une session) pour vérifier rapidement.
- Conservez un dossier `historique-poker/` pour centraliser vos exports.
- Gardez les captures à jour si l'interface des rooms évolue.
